in fields, where deemed necessary. This information makes it easier to review past changes. When done
click the `Commit changes` button in the modal. That's it! Refresh the site in your browser to confirm
your changes had the desired effect. There may be a slight delay while the changes are deployed.

## Domain Name Configuration
Documentation can be found [here](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site).

To use a custom domain for this site, you'll need to make these modifications:

### Add Your Custom Domain to Your Repository
1. In your GitHub repository, navigate to the Settings tab.
2. Scroll down to the "Pages" section.
3. In the "Custom domain" field, enter your custom domain name example.com and save the changes.

### Configure Your DNS Settings
1. Go to your domain registrar's website and log in.
2. Update the DNS records to point to GitHub Pages. Typically, you'll need to set the following DNS records:

#### "A" records:

* `@`     `185.199.108.153`
* `@`     `185.199.109.153`
* `@`     `185.199.110.153`
* `@`     `185.199.111.153`

* `www     example.com.github.io`
